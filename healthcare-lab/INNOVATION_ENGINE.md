# INNOVATION_ENGINE.md — Gap → Opportunity → Concept → MVP

The research does not stop at "what do we know." It continues into "what has nobody
solved, and what should we build." Innovation here is **evidence-anchored**, scored,
and ranked — never novelty for its own sake.

## Step 1 — Map the landscape
- **Current state:** what actually happens today in this care pathway?
- **Existing solutions:** what products/interventions already exist? (name them)
- **Evidence-backed interventions:** which of those actually work (from the ledger)?

## Step 2 — Locate the gaps (all seven — a gap is only real if you searched for it)
- **Unmet need:** what problem is still unsolved for the patient/clinician/system?
- **Evidence gap:** what do we *not know* (no/weak studies)?
- **Workflow gap:** where does the process break operationally?
- **Technology gap:** what could technology improve that it currently doesn't?
- **Market gap:** where is there a commercial opening?
- **Regulatory constraint:** what would block deployment (SFDA/SDAIA/etc.)?
- **White space:** the opportunity no current solution covers.

## Step 3 — Generate opportunities
Each opportunity must trace to a specific gap above and to evidence in the ledger.
An opportunity with no gap and no evidence basis is a `HYPOTHESIS`, labeled as such.

## Step 4 — Score & rank (do NOT skip; novelty ≠ value)
Score each opportunity 1–5 on every dimension, then rank by weighted total:

| Dimension | 1 (weak) → 5 (strong) |
|-----------|------------------------|
| Clinical value | negligible → life-saving / major QoL |
| Evidence strength | speculative → backed by high-certainty evidence |
| Problem severity | minor annoyance → major morbidity/mortality/cost |
| Unmet need | crowded → genuinely unsolved |
| Feasibility | years/unclear → buildable now |
| Saudi relevance | generic → directly serves Saudi priorities |
| Regulatory complexity | 5 = simple path; 1 = SaMD/AI heavy approval |
| Implementation difficulty | 5 = drops into existing workflow; 1 = system change |
| Economic potential | none → strong, defensible |
| Differentiation | me-too → hard to copy |
| Validation cost | 5 = cheap/fast to test; 1 = large trial needed |

Show the matrix. The top-ranked opportunity gets the full translation below.

## Step 5 — Research-to-Product translation (prove the whole chain)
No jump from `Paper → Startup`. Every link must hold:

```
Problem → Evidence → User → Workflow → Intervention → Technology → MVP → Metric → Experiment → Go/No-Go
```

- **MVP:** the smallest thing that tests the riskiest assumption.
- **Metric:** the one number that says "keep going" or "stop."
- **Experiment:** how you'll get that number cheaply (→ VALIDATION_FRAMEWORK.md).
- **Go/No-Go:** the threshold decided *before* running the experiment.

## Guardrail
If the evidence is `Insufficient` or `Evidence not found`, the honest innovation move
is often "the opportunity is to generate the missing evidence" (a study/registry),
not "build a product on a void." Say that when it's true.
